DATA CLEANING AI AGENT :

An AI powered web application that automatically analyzes, detects and cleans common data quality issues in CSV and Excel datasets.

Features :

. Upload CSV/Excel datasets

. Detect missing values, duplicates, invalid values, and outliers

. Automatically clean and normalize data

. Compare data quality before and after cleaning

. Generate AI-based explanations of cleaning operations

. Maintain a detailed cleaning log

. Download the cleaned dataset and report
